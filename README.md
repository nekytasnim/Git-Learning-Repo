# GitHub Learning Repository

Welcome to my GitHub learning repository! This repository is a playground for me to practice Git and GitHub commands, experiment with version control, and understand collaborative development workflows.

## 🚀 What This Repository Contains
- Sample files and commits for learning Git basics
- Experiments with branches, merges, and rebases
- Testing out Git commands like `clone`, `push`, `pull`, `fetch` and more
- Resolving merge conflicts and exploring best practices

## 📌 Topics I'm Exploring
- Initializing a Git repository (`git init`)
- Adding and committing changes (`git add`, `git commit`)
- Working with branches (`git branch`, `git checkout`)
- Merging and rebasing (`git merge`, `git rebase`)
- Undoing changes (`git reset`, `git stash`)
- Collaborating with remotes (`git push`, `git pull`, `git fetch`)
- Handling merge conflicts
- Understanding GitHub features 

## 🛠️ How to Use This Repository
Feel free to explore the commits and branches to see my learning progress. If you're also learning GitHub, you can fork this repo and try out different Git operations.
